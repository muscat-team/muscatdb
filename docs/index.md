# muscat-db

muscat-db is the web app the MuSCAT team uses to ingest observation logs, run
photometry, fit transits and TTVs, and plan LCO observations.

This site is the written documentation. The [UI tour](/muscatdb/home/) is a
static snapshot of the app (globe, logs, catalogs). Live data and actions are
off.

New to muscat-db? Start with [Getting started](using/getting-started.md), which
walks one target from sign-in to a transit fit.
