# muscat-db

muscat-db は、MuSCAT チームが観測ログの取り込み、測光、トランジットとトランジット時刻変動（TTV）の解析、LCO での観測計画に使うウェブアプリです。

このサイトでは使い方と解析手法を解説します。[画面ツアー](/muscatdb/home/)では、サンプルデータを使って地球儀、観測ログ、カタログを閲覧できます。実データの取得やジョブの実行には本番のアプリを使います。

初めての方は[はじめに](using/getting-started.md)をご覧ください。ログインから、ひとつの天体のトランジットをフィットするまでを順に説明します。
