# 一晩の観測を確認する

ナビゲーションの **Obs** を開き、装置、観測日、CCD の順に選ぶと、その晩のフレームを観測ログで確認できます。[画面ツアーの Obs](/muscatdb/home/obs/) でもサンプルデータを使って同じ操作ができます。測光やトランジット解析のフォームも閲覧できますが、ツアーではジョブは起動しません。

## 測光の図を見る

スクロールすると、表示サイズに合わせたプレビューが読み込まれます。図をクリックすると元の解像度で開きます。**Master Calibration Images** を展開すると、較正用のマスター画像が表示されます。動画は最初は静止画で、**Play animation** と **Stop animation** で読み込みと再生を制御できます。モバイルでは初回はチャットが折り畳まれ、以降は自分で選んだ表示状態が保存されます。

ブラウザーは図をキャッシュし、ページを開くたびに更新を確認するため、測光を再実行すると新しい図が表示されます。プレビューの生成は、元の解析結果や FITS ファイル、CSV や出力一式のダウンロードには影響しません。
