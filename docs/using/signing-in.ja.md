# ログインと閲覧権限

[MuSCAT-DB](https://db.muscat-team.jp) にログインするには、メールで届く使い捨ての暗証番号（PIN）を使います。

## 初回ログインの前に

管理者に、実際に使用するメールアドレスを伝えてください。管理者は MuSCAT-DB のアカウントを作成し、アドレスをアカウントに紐付けたうえで、ログイン許可リストにも登録します。アドレスの入力間違いにご注意ください。

## ログインする

1. ブラウザーで [本番サイト](https://db.muscat-team.jp) を開きます。
2. 登録したメールアドレスを入力します。
3. メールで届いた PIN をログイン画面に入力します。認証に成功するとホーム画面が開きます。

**No access** と表示された場合は、認証に使ったアドレスが MuSCAT-DB のアカウントに紐付いていません。画面に表示されたアドレスを管理者に伝え、誤りがある場合は使用したいアドレスも伝えてください。

## 閲覧できるデータとチャット

チームメンバーはチームのデータを閲覧できます。共同研究者が閲覧できるのは、所属グループに許可された観測課題や天体です。測光、トランジット、TTV の解析結果は、その入力データをすべて閲覧できる場合に表示されます。自分が作成した結果は常に閲覧できます。必要なデータが見えない場合は管理者にご相談ください。

チーム用チャットはチームメンバーが使用できます。共同研究者には、所属する共有グループごとにチャットルームがあります。

## ログアウトする

ウィンドウ幅を 1240 ピクセル以下にするとナビゲーションメニューが表示されます。メニューから **Log out** を選びます。幅を変えずにログアウトするには、サイトの `/logout` を開きます。本番環境のアドレスは <https://db.muscat-team.jp/logout> です。

アカウントや権限の問題は招待者を通して管理者にお問い合わせください。[不具合報告](https://github.com/muscat-team/muscatdb/issues)には、アカウント情報、メールアドレス、PIN を記載しないでください。
